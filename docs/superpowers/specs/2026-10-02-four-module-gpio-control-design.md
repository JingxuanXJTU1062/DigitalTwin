# 四模块四位 GPIO 启停控制设计

## 目标

将现有上位机控制从 3 位扩展为 4 位，并用四路持续 GPIO 电平分别控制进料、去鳞、去内脏和出料模块。对应位为 1 时允许或启动模块，为 0 时强制停止模块。出料模块保留压力触发流程，但出料控制位为 0 时拥有最高优先级，必须取消待执行动作并停止传送带。

## 控制位与接线

四位顺序固定如下：

| 位 | 模块 | F407 输出 | 原机板输入 |
| --- | --- | --- | --- |
| Flag1 | 进料 | PE4 | PA6 |
| Flag2 | 去鳞 | PE5 | PA6 |
| Flag3 | 去内脏 | PE6 | PA6 |
| Flag4 | 出料 | PC2 | PA6 |

所有控制板必须与 F407 共地。PE7 不使用，因为 F407 启动代码已将其配置给 FMC 外部存储器。

F407 启动时四路输出均为低电平。主机命令超时后，四路输出也全部强制为低电平。

## 上位机与 F407 协议

PC 主机维护四个完全由主机设置的布尔 Flag，顺序为进料、去鳞、去内脏、出料。

正式控制链路使用四个 Modbus 线圈：

- Coil 0：Flag1，进料。
- Coil 1：Flag2，去鳞。
- Coil 2：Flag3，去内脏。
- Coil 3：Flag4，出料。

PC 每次周期刷新时写入四个线圈，并读取四个线圈核对状态。F407 的单线圈写入、多线圈写入、读取和超时清零逻辑均覆盖四路。

旧兼容命令帧同步扩展为：

```text
$CMD,f1,f2,f3,f4*CS\r\n
```

其中每个字段只能为 `0` 或 `1`，`CS` 为 `CMD,f1,f2,f3,f4` 字节的 XOR。字段数错误、字段值非法或校验错误时，不改变任何 GPIO。

## 原机板 GPIO 输入策略

四块原机控制板均使用 PA6 作为主机控制输入。前三块板的 PA6 由原来的 TTP223 上升沿输入改为普通持续电平输入；出料板的 PA6 当前未被实际运行流程占用，新增为控制输入。

每块板在主循环轮询 PA6，并保存上一次已应用状态。只在电平变化时执行一次启停动作：

- 低到高：执行模块启动动作。
- 高到低：执行模块停止动作。
- 电平不变：不重复发送电机命令。

上电初始化完成后读取 PA6 的真实状态。PA6 为低时保持停止；PA6 为高时启动一次。

## 进料模块行为

高电平启动时保留原参数：

- Emm-V5 地址 1：方向 0，50 RPM。
- Emm-V5 地址 3：方向 1，35 RPM。
- X-V5 地址 2：方向 1，速度字段 500，即 50 RPM。

低电平停止时：

- 对 Emm 地址 1、3 调用 `Emm_V5_Stop_Now()`。
- 对 X 地址 2 调用 `X_V5_Stop_Now()`。

驱动器保持使能，以便下次高电平直接重新启动。

## 去鳞模块行为

高电平启动时保留原参数：

- X 地址 1：30 RPM。
- X 地址 2：200 RPM。
- X 地址 3：1000 RPM。
- X 地址 4：2000 RPM。
- X 地址 5：200 RPM。
- 直流电机 1：正向 20% PWM。
- 直流电机 2：反向 20% PWM。

低电平停止时：

- 对 X 地址 1 至 5 调用 `X_V5_Stop_Now()`。
- 调用 `Motor1_SetSpeed(0)` 和 `Motor2_SetSpeed(0)`。

## 去内脏模块行为

高电平启动时保留原参数：

- X 地址 1：15 RPM。
- X 地址 2：15 RPM。
- X 地址 3：1500 RPM。
- 直流电机 1：正向 50% PWM。

低电平停止时：

- 对 X 地址 1 至 3 调用 `X_V5_Stop_Now()`。
- 调用 `Motor1_SetSpeed(0)`。

USART2 控制的 Emm 地址 1 与 Flag3 保持独立。它只响应出料板发来的 `MOTOR_START` 和 `MOTOR_STOP`：

- `MOTOR_START`：保留原位置命令，方向 1、100 RPM、25000 脉冲、绝对位置。
- `MOTOR_STOP`：调用 `Emm_V5_Stop_Now(1, 0)`。

## 出料模块行为

Flag4 是最高优先级的总允许信号：

- PA6 为低：禁止压力触发，取消尚未完成的 2 秒等待，并通过 USART2 发送一次 `MOTOR_STOP\r\n`。
- PA6 为高：允许压力检测。

在允许状态下，压力电压低于 0.035 V 时进入 2 秒确认等待。现有工程没有连续系统毫秒计数器，因此等待实现为 20 个 100 ms 主循环片段的可取消倒计时，而不是一次 `delay_ms(2000)` 阻塞；到期时再次确认 PA6 仍为高，然后发送 `MOTOR_START\r\n`。如果 PA6 刚变高时压力已经低于阈值，也进入相同的 2 秒确认流程。Flag4 低电平的最迟处理时间为一个主循环片段，约 100 ms。

压力恢复到不低于 0.035 V 后重新武装下一次压力触发。传送带在启动后持续运行，直到 Flag4 变低并收到 `MOTOR_STOP`。

## 时序与安全处理

多电机启动仍保留原命令顺序、速度、方向和必要命令间隔。每条启动命令之间重新读取 PA6；若其已经变低，则中止剩余启动步骤并执行整组停止，避免低电平到达后仍继续启动后续电机。

停止使用立即停止命令而不失能驱动器，以保留当前位置基准并支持频繁启停。直流电机停止时将 PWM 设为 0。

主机或 F407 复位、尚未收到有效命令、通信命令超时以及明确发送 0 时，GPIO 输出均为低电平。原机板因此进入或保持停止状态。

## 测试与验证

测试覆盖以下行为：

1. Python 主机正确打包、写入并读回四个 Modbus 线圈。
2. F407 支持四线圈读取、单线圈写入、多线圈写入和通信超时全清零。
3. 旧 `$CMD` 兼容解析只接受四个合法布尔字段，并正确驱动 PE4、PE5、PE6、PC2。
4. 进料、去鳞、去内脏板在 PA6 高电平时启动、低电平时停止，重复电平不会重复发送命令。
5. 多电机启动期间 PA6 变低会中止剩余启动并执行停止。
6. 出料板低电平会取消 2 秒压力等待并发送 `MOTOR_STOP`；只有 Flag4 为高时压力才能触发 `MOTOR_START`。
7. 更新引脚与协议文档，并检查所有接线说明的四位顺序一致。
8. 使用现有 Keil 工程进行编译验证；若本机缺少可用编译器，则运行主机测试和静态契约测试，并明确记录未能完成的嵌入式编译验证。

## 不在本次范围内

- 不修改现有电机速度、方向、加速度、压力阈值或位置脉冲数。
- 不改变传感器数据上传协议和各传感器下位机的数据采集逻辑。
- 不新增电机驱动硬件；出料仍通过 USART2 控制去内脏板上的 Emm 地址 1。
- 不使用 PE7，也不重配 FMC 外部存储器引脚。
