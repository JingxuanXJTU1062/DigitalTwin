# DigitalTwin 电控工程

2026—2027 机械创新设计大赛数字孪生项目的电控代码与配置记录。仓库包含原机执行机构程序、5 个传感器下位机工程，以及 STM32F407 + ESP8266 上位通信程序。

## 目录

- `原机代码/`：进料、去鳞、红外跟随、开膛去内脏、出料 5 套 STM32F103C8 原机程序。
- `xiaweiji/`：5 个传感器采集下位机工程。
- `WiFi/F407_04/`：STM32F407 上位汇总与 Modbus TCP 服务端。
- `WiFi/mcu_wifi_listener.py`：PC 端 Modbus TCP 客户端示例。
- `docs/上位机与5个下位机引脚清单.md`：完整引脚、板间接线与串口链路说明。
- `原机代码/原机代码功能与外设引脚总结.md`：原机程序的详细功能、参数与风险说明。

## 原机代码配置

5 套程序均面向 STM32F103C8，使用 STM32F10x 标准外设库、裸机循环和 115200-8-N-1 串口。闭环步进驱动器通过 USART1（PA9/PA10）控制；四路运行信号由 F407 输出，并要求所有控制板共地。

| 模块 | F407 控制输出 | 原机输入 | 当前动作配置 |
| --- | --- | --- | --- |
| 进料 | PE4 / Flag1 | PA6 | 高电平启动 2 台 Emm-V5（50、35 RPM）和 1 台 X-V5（50 RPM），低电平停止 |
| 去鳞 | PE5 / Flag2 | PA6 | 高电平启动 5 台 X-V5（30、200、1000、2000、200 RPM）及 2 路 20% PWM 直流电机，低电平停止 |
| 红外跟随 | 独立运行 | PA7 红外输入 | 上电回零；红外由遮挡变为未遮挡后，执行 3200 脉冲往返动作 |
| 开膛去内脏 | PE6 / Flag3 | PA6 | 高电平启动 3 台 X-V5（15、15、1500 RPM）及 1 路 50% PWM 直流电机；另由 USART2 接收出料板命令控制 Emm-V5 |
| 出料 | PC2 / Flag4 | PA6 | 高电平发送 `MOTOR_RUN`；低电平时压力事件发送 `MOTOR_START`，无事件发送 `MOTOR_STOP` |

出料板到开膛板使用 USART2（出料 PA2/TX → 开膛 PA3/RX），命令为 `MOTOR_RUN\r\n`、`MOTOR_START\r\n`、`MOTOR_STOP\r\n`。更完整的电机地址、方向、PWM 引脚及已知冲突见[原机代码功能与外设引脚总结](原机代码/原机代码功能与外设引脚总结.md)。

## 传感器配置

| 下位机 / ID | 传感器与接口 | 上传链路 |
| --- | --- | --- |
| `F103jinliao01` / `0x01` | PA6/TIM3_CH1 霍尔测速；PB0 低有效红外到料检测 | PA9/USART1_TX → F407 PC11/UART4_RX，10 字节帧 |
| `F103jinliao02` / `0x02` | PA6/TIM3_CH1 霍尔；PA1/ADC1_IN1 压力 AO；PB0 压力 DO | PA9/USART1_TX → F407 PA10/USART1_RX，12 字节帧 |
| `F407HALL` / `0x03` | 3 路霍尔（PA0、PA3、PA2）；2 路 VL6180X（I2C1、I2C2） | PA9/USART1_TX → 出料板 PA10/RX；由出料板汇总到 F407，16 字节帧 |
| `F407HALL03` / `0x04` | 2 路霍尔（PA0、PA3）；3 路 VL6180X（I2C1、I2C2、I2C3） | PA9/USART1_TX → F407 PA3/USART2_RX，17 字节帧 |
| `F103chuliao05` / `0x05` | PA6/TIM3_CH1 霍尔；PA1/ADC1_IN1 压力 AO；PB0 压力 DO | PA9/USART1_TX → F407 PD2/UART5_RX，12 字节自身帧，可紧跟 `0x03` 的 16 字节帧 |

下位机二进制帧统一以 `AA 55` 开头，包含模块 ID、载荷长度和末尾 XOR 校验。压力值按 12 位 ADC 的 `0~4095` 线性映射到 `0~100 kPa`；VL6180X 的 I2C 总线为 100 kHz，SCL/SDA 需上拉至 3.3 V（模块未自带上拉时建议约 4.7 kΩ）。完整引脚及接线要求见[上位机与 5 个下位机引脚清单](docs/上位机与5个下位机引脚清单.md)。

## WiFi 通信协议与使用方法

正式链路如下：

```text
PC Python 客户端
  → WiFi / Modbus TCP（192.168.4.1:502）
  → ESP8266 字节透传
  → USART3（PB10/PB11）
  → STM32F407 Modbus TCP 服务端
  → 各下位机串口与四路 GPIO 控制
```

通信参数：

- ESP8266 工作在 AP 模式，默认热点 `BinghuoLink`，密码 `wildfire123`；服务地址 `192.168.4.1:502`。
- Modbus Unit ID 为 `1`。
- 功能码 `0x04` 读取输入寄存器 `0~29`，功能码 `0x01` 读取线圈，`0x05`/`0x0F` 写单个/多个线圈。
- Coil `0~3` 依次控制进料、去鳞、开膛去内脏、出料，即 F407 的 PE4、PE5、PE6、PC2。
- 传感器数据超过 500 ms 未更新会标记失效；控制命令超过 1500 ms 未刷新时，4 路输出自动清零。

输入寄存器的主要映射：

| 地址 | 内容 |
| --- | --- |
| 0~3 | 协议版本、序号、5 路数据有效位、状态位 |
| 10~11 | `0x01` 进料 1：角速度、到料状态 |
| 12~14 | `0x05` 出料：角速度、压力、落料状态 |
| 15~17 | `0x02` 进料 2：角速度、压力、落料状态 |
| 18~23 | `0x03`：3 路角速度、2 路距离、测距状态 |
| 24~29 | `0x04`：2 路角速度、3 路距离、测距状态 |

PC 使用步骤：

1. 烧录并启动 `WiFi/F407_04`，确认 ESP8266 已进入 AP 与 TCP 服务模式。
2. PC 连接热点 `BinghuoLink`。
3. 根据需要修改 `WiFi/mcu_wifi_listener.py` 顶部的 `FLAG1`~`FLAG4` 控制值。
4. 使用 Python 3 运行：

   ```powershell
   python .\WiFi\mcu_wifi_listener.py
   ```

脚本默认以 5 Hz 读取 30 个输入寄存器，每 0.5 秒刷新并回读 4 个控制线圈；掉线后每 3 秒自动重连。旧 `$CMD,f1,f2,f3,f4*CS` 文本协议仅保留作兼容，正式链路使用 Modbus TCP。

> 接线前请确认所有板卡共地、串口 TX/RX 交叉连接，并确保所有传感器信号不超过 3.3 V。
