# 原机代码功能与外设引脚总结

## 1. 文档说明

本文档分析以下 5 套 STM32 原机程序：

1. `1_进料`
2. `2_去鳞`
3. `3_红外跟随`
4. `4_开膛去内脏`
5. `5_出料`

分析以各工程当前 `APP/main.c` 的实际调用为准。工程中虽然包含、甚至编译了某些驱动文件，但只要当前主程序没有初始化或调用，就不计入“实际运行使用”，而是在“存在但未实际使用”中另行说明。

所有工程的目标器件均为 **STM32F103C8（Cortex-M3）**，采用 STM32F10x 标准外设库和裸机循环，没有使用 RTOS。

> 2026-10-04 控制映射：Flag1=进料（F407 PE4→PA6）、Flag2=去鳞（PE5→PA6）、Flag3=去内脏（PE6→PA6）、Flag4=出料（PC2→PA6）。Flag1～Flag3高电平运行、低电平停止；Flag4与压力条件采用OR逻辑。四块板必须与F407共地。

> 当前配置：出料压力触发已启用（`PRESSURE_TRIGGER_ENABLED=1`）。Flag4控制连续运行，压力事件控制有限位置运动。

> 说明：代码可以确定电机驱动器类型、地址、方向和速度等软件参数，但无法仅凭代码确定每台电机在机械结构上具体对应哪一根输送辊、毛刷、刀具或水泵；此类对应关系还需要结合电气原理图和接线表确认。

---

## 2. 整体控制结构

整机代码可概括为：

```text
进料
  PA6高电平启动、低电平停止
  → 2台Emm-V5电机 + 1台X-V5电机持续运行

去鳞
  PA6高电平启动、低电平停止
  → 5台X-V5电机 + 2台直流电机持续运行

红外跟随
  Emm-V5电机上电回零和初始定位
  → PA7红外由“遮挡”变为“未遮挡”
  → 执行固定位置往返动作

开膛去内脏
  Path 1：PA6高电平启动、低电平停止
  → 3台X-V5电机 + 1台直流电机启动

  Path 2：USART2收到MOTOR_RUN/MOTOR_START/MOTOR_STOP
  → 1台Emm-V5电机连续运行/有限位置运动/立即停止

出料
  Flag4高电平 → USART2发送MOTOR_RUN并连续运行
  Flag4低电平且PB0压力模拟电压达到或高于0.035 V并持续约2秒
  → USART2发送一次MOTOR_START并执行25000脉冲有限运动
  Flag4低电平且没有压力事件 → USART2发送MOTOR_STOP
  → 触发开膛去内脏模块的Path 2
```

五套程序中的明确跨控制板通信为：

```text
出料板 USART2_TX（PA2）
        ↓ 发送 "MOTOR_RUN\r\n"、"MOTOR_START\r\n" 或 "MOTOR_STOP\r\n"
开膛板 USART2_RX（PA3）
        ↓
开膛板按命令控制Emm#1连续运行、有限位置运动或立即停止
```

## 3. 公共驱动与通信功能

### 3.1 `board.c`：板级初始化

五套程序的 `board_init()` 主要完成：

- 配置 NVIC 中断优先级分组为 `NVIC_PriorityGroup_4`。
- 使能 GPIOA、GPIOB、AFIO 时钟。
- 使能 USART1、USART2 时钟。
- 初始化 USART1 和 USART2。
- 关闭 JTAG 功能，保留 SWD 调试接口。

公共串口配置如下：

| 串口 | 引脚 | 配置 | 主要用途 |
|---|---|---|---|
| USART1 | PA9 TX、PA10 RX | 115200，8位，无校验，1停止位 | Emm-V5/X-V5电机驱动器总线 |
| USART2 | PA2 TX、PA3 RX | 115200，8位，无校验，1停止位 | 调试打印或控制板之间通信 |

USART1通常启用：

- RXNE接收非空中断：逐字节接收。
- IDLE空闲中断：将一次空闲判定为一帧结束。

开膛去内脏工程还启用了USART2的RXNE和IDLE中断，用来接收出料板发送的文本命令。

### 3.2 `Emm_V5.c`：Emm-V5闭环步进驱动协议

该驱动通过USART1向Emm-V5闭环步进电机驱动器发送二进制命令，提供：

- 电机使能/失能。
- 速度模式控制。
- 位置模式控制。
- 立即停止。
- 读取实时位置、速度和状态。
- 设置回零参数。
- 触发回零。

代码中速度模式参数单位为 **RPM**。

### 3.3 `X_V5.c`：X固件闭环步进驱动协议

X-V5驱动同样通过USART1发送二进制命令。

当前程序主要使用：

- 电机使能。
- 速度模式控制。

X固件速度字段单位是 **0.1 RPM**，因此：

```text
speed = 150    → 15.0 RPM
speed = 500    → 50.0 RPM
speed = 2000   → 200.0 RPM
speed = 15000  → 1500.0 RPM
```

### 3.4 `TTP223.c`：PA6 主机控制输入

进料、去鳞、开膛去内脏和出料工程均使用PA6：

| 项目 | 配置 |
|---|---|
| GPIO | PA6 |
| 输入模式 | 下拉输入 |
| 外部中断 | 不使用 |
| 识别方式 | 主循环持续读取高/低电平 |
| 高电平 | 启动模块或允许压力触发 |
| 低电平 | 强制停止模块 |

主循环保存上次状态，仅在电平变化时下发一次启停命令；多电机启动过程中也会重新检查PA6。

### 3.5 `Motor.c`和`PWM.c`：H桥直流电机

直流电机通过两个方向GPIO和一路PWM控制：

- 正速度：一侧方向脚置1，另一侧置0。
- 负速度：方向反转。
- 速度绝对值直接作为0～100的PWM比较值。

去鳞工程使用经过调整的引脚版本；开膛工程使用通用版本，两者引脚分配不同。

### 3.6 `PressureSensor.c`：模拟压力传感器

压力模块提供：

- AO模拟输出：PB0，对应ADC1_IN8。
- DO数字输出：PB1。

ADC配置：

- ADC1独立模式。
- 单通道、非连续转换。
- 软件触发。
- 12位右对齐。
- 采样时间239.5周期。
- ADC时钟为PCLK2/6。

当前实际判定只使用AO模拟输出，DO虽然初始化，但没有被主程序读取。

## 4. 进料模块

源代码入口：[`原机代码/1_进料/APP/main.c`](原机代码/1_进料/APP/main.c)

### 4.1 实现功能

启动过程：

1. 调用`board_init()`，初始化USART1、USART2和NVIC。
2. 初始化PA6下拉控制输入。
3. 阻塞等待3秒。
4. 使能Emm地址1。
5. 使能Emm地址3。
6. 使能X地址2。
7. 进入主循环持续读取PA6。

PA6由低变高后启动三台电机：

| 驱动器 | 地址 | 控制模式 | 方向 | 速度 | 加速度 |
|---|---:|---|---:|---:|---:|
| Emm-V5 | 1 | 速度模式 | 0 | 50 RPM | 0，直接启动 |
| Emm-V5 | 3 | 速度模式 | 1 | 35 RPM | 0，直接启动 |
| X-V5 | 2 | 速度模式 | 1 | 50.0 RPM | 65535 RPM/s |

PA6变低时分别调用两台Emm和一台X驱动器的立即停止命令；再次变高可重新启动。

### 4.2 实际使用的电机与传感器

- Emm-V5闭环步进电机：2台，地址1和3。
- X-V5闭环步进电机：1台，地址2。
- PA6上位机控制输入：1路。

### 4.3 实际使用的外设和引脚

| 外设 | 引脚 | 用途 |
|---|---|---|
| USART1 | PA9 TX、PA10 RX | 控制3台闭环步进驱动器 |
| GPIO输入 | PA6 | Flag1持续电平输入 |
| SysTick | 内核外设 | 3秒启动延时和命令间隔 |

USART2的PA2/PA3虽然已初始化，但当前主程序没有使用。

### 4.4 运行特点

- 高电平期间电机持续运行，低电平立即停止。
- 没有故障反馈和运动状态检查。
- 每次低到高变化均可重新执行完整启动，稳定电平不重复下发命令。
- 工程中包含直流电机和PWM驱动，但没有调用`Motor_Init()`，实际不使用。

## 5. 去鳞模块

源代码入口：[`原机代码/2_去鳞/APP/main.c`](原机代码/2_去鳞/APP/main.c)

### 5.1 实现功能

启动过程：

1. 初始化USART1和USART2。
2. 初始化两路H桥直流电机及PWM。
3. 初始化PA6下拉控制输入。
4. 等待3秒。
5. 依次使能X驱动器地址1～5。
6. 进入主循环持续读取PA6。

PA6由低变高后执行：

| 执行器 | 地址/通道 | 方向 | 实际速度/占空比 |
|---|---|---:|---:|
| X-V5 | 1 | 0 | 30 RPM |
| X-V5 | 2 | 0 | 200 RPM |
| X-V5 | 3 | 1 | 1000 RPM |
| X-V5 | 4 | 0 | 2000 RPM |
| X-V5 | 5 | 1 | 200 RPM |
| 直流电机1 | DC1 | 正向 | 20% PWM |
| 直流电机2 | DC2 | 反向 | 20% PWM |

五台X-V5电机的加速度参数均为65535 RPM/s。

### 5.2 实际使用的电机与传感器

- X-V5闭环步进电机：5台，地址1～5。
- H桥直流电机：2台。
- PA6上位机控制输入：1路。

> 两路直流电机是否实际连接水泵，需要根据接线图确认；代码只能确定它们是两路可正反转PWM直流负载。

### 5.3 实际使用的外设和引脚

| 外设/功能 | 引脚 | 用途 |
|---|---|---|
| USART1 | PA9 TX、PA10 RX | 控制5台X-V5驱动器 |
| GPIO输入 | PA6 | Flag2持续电平输入 |
| TIM2_CH2 | PA1 | 直流电机1 PWM |
| GPIO输出 | PA4、PA5 | 直流电机1方向 |
| TIM3_CH3 | PB0 | 直流电机2 PWM |
| GPIO输出 | PB10、PB11 | 直流电机2方向 |
| SysTick | 内核外设 | 启动和命令间隔延时 |

PWM参数为：

- ARR = 99。
- PSC = 35。
- 在72 MHz定时器时钟下，PWM频率约20 kHz。

### 5.4 运行特点

- 所有电机在PA6高电平时持续运行，低电平时五台X驱动立即停止且两路直流PWM归零。
- 没有堵转检测或驱动报警处理。
- Emm-V5代码虽然被编译，但当前主程序没有使用Emm电机。

## 6. 红外跟随模块

源代码入口：[`原机代码/3_红外跟随/APP/main.c`](原机代码/3_红外跟随/APP/main.c)

### 6.1 当前实际实现的功能

当前主程序并没有启用VL53L0X距离跟随，实际执行的是“红外遮挡解除触发的固定位置往返”。

启动过程：

1. 初始化USART1、USART2和PA7红外输入。
2. 等待3秒。
3. 使能Emm地址1。
4. 设置地址1的堵转回零参数。
5. 触发模式2回零。
6. 固定等待5秒。
7. 以200 RPM发送方向1、25600脉冲的绝对位置命令。

循环过程：

1. 读取PA7红外状态。
2. PA7为低电平时，`ir_sensor_blocked()`返回1，表示被遮挡。
3. 当状态从1变成0时，即由“遮挡”变为“未遮挡”，开始触发。
4. 等待20 ms后再次确认仍未遮挡。
5. 以20 RPM发送方向1、3200脉冲绝对位置命令。
6. 等待5秒。
7. 以20 RPM发送方向0、3200脉冲绝对位置命令。
8. 返回循环，等待下一次遮挡和解除。

### 6.2 实际使用的电机与传感器

- Emm-V5闭环步进电机：1台，地址1。
- 低电平有效的数字红外传感器/光电开关：1个。

### 6.3 实际使用的外设和引脚

| 外设/功能 | 引脚 | 用途 |
|---|---|---|
| USART1 | PA9 TX、PA10 RX | Emm-V5电机命令和位置回传 |
| GPIO输入 | PA7 | 红外遮挡检测，上拉输入、低电平有效 |
| SysTick | 内核外设 | 3秒、5秒、20 ms和50 ms阻塞延时 |

USART2虽然初始化为PA2/PA3，但当前`main()`没有调试输出。

### 6.4 工程中存在但未实际运行的功能

工程中包含完整的VL53L0X和夹爪跟随代码，包括：

- I2C1，PB6 SCL、PB7 SDA，100 kHz。
- VL53L0X激光测距。
- 100～300 mm有效距离筛选。
- 距离低通滤波。
- 根据距离估计物体宽度。
- 宽度FIFO延迟跟随。
- 根据目标宽度调整夹爪间距。
- 电机位置自动回传解析。

但是当前`main()`没有调用：

- `VL53_App_Init()`。
- `VL53_App_Update()`。
- `Gripper_Init()`。
- `Gripper_Update()`。

因此上述功能在当前烧录逻辑中不会运行，不能把当前固件描述为“根据距离实时跟随”。

### 6.5 已发现的严重问题

`Emm_V5_Origin_Modify_Params()`内部声明：

```c
uint8_t cmd[16];
```

但实际写到了`cmd[19]`，并发送20字节。该函数在红外主程序启动时确实会调用，会产生栈内存越界风险。数组至少应能容纳20字节。

## 7. 开膛去内脏模块

源代码入口：[`原机代码/4_开膛去内脏/APP/main.c`](原机代码/4_开膛去内脏/APP/main.c)

### 7.1 启动过程

1. 初始化USART1和USART2。
2. 初始化两路直流电机的方向GPIO和PWM。
3. 初始化PA6下拉控制输入。
4. 等待3秒。
5. 使能Emm地址1。
6. 使能X地址1、3、2。
7. 进入主循环，同时处理PA6电平和USART2命令。

### 7.2 Path 1：PA6 电平控制

PA6由低变高时依次启动以下执行器；PA6变低时立即停止整组：

| 执行器 | 地址/通道 | 方向 | 实际速度/占空比 |
|---|---|---:|---:|
| X-V5 | 1 | 1 | 15 RPM |
| X-V5 | 2 | 0 | 15 RPM |
| X-V5 | 3 | 0 | 1500 RPM |
| 直流电机1 | DC1 | 正向 | 50% PWM |

注意：Emm地址1在上电时被使能，但Flag3只控制X地址1～3和直流电机1，不控制Emm地址1。

### 7.3 Path 2：出料板串口触发

USART2使用RXNE中断接收字节，使用IDLE中断判断一帧结束。

主循环检测到接收帧后，识别以下命令：

```text
MOTOR_START
MOTOR_RUN
MOTOR_STOP
```

`MOTOR_RUN`匹配后向Emm地址1发送连续速度命令：

| 参数 | 数值 |
|---|---:|
| 控制模式 | 速度模式，持续运行 |
| 方向 | 1 |
| 速度 | 100 RPM |
| 加速度 | 0，直接启动 |

`MOTOR_START`用于压力事件，执行100 RPM、25000脉冲的有限位置运动；完成后驱动器自然停止。

`MOTOR_STOP`匹配后调用`Emm_V5_Stop_Now(1, 0)`。

### 7.4 实际使用的电机与传感器

- X-V5闭环步进电机：3台，地址1、2、3。
- Emm-V5闭环步进电机：1台，地址1，由串口Path 2启动连续速度运行。
- H桥直流电机：实际使用1台，即DC1。
- PA6上位机控制输入：1路。
- USART2上游触发信号：来自出料板。

### 7.5 实际使用的外设和引脚

| 外设/功能 | 引脚 | 用途 |
|---|---|---|
| USART1 | PA9 TX、PA10 RX | 发送Emm/X电机命令 |
| USART2_RX | PA3 | 接收出料板的`MOTOR_RUN`/`MOTOR_START`/`MOTOR_STOP` |
| GPIO输入 | PA6 | Flag3持续电平输入 |
| TIM2_CH2 | PA1 | 直流电机1 PWM |
| GPIO输出 | PA4、PA5 | 直流电机1方向 |
| SysTick | 内核外设 | 启动和动作间隔延时 |

### 7.6 存在但未实际使用

- 压力传感器驱动被编入工程，但没有调用`PressureSensor_Init()`或读取函数。
- 直流电机2的方向和PWM被初始化，但主程序没有调用`Motor2_SetSpeed()`。

### 7.7 引脚与总线风险

#### PA6冲突

- `Motor_Init()`将PA6配置为直流电机2方向输出。
- `TTP223_Init()`随后又将PA6配置为上位机控制下拉输入。

最终PA6作为上位机控制输入使用，直流电机2方向输出失效。

#### PA2冲突

- `board_init()`先将PA2配置为USART2_TX。
- `PWM_Init()`随后将PA2配置为TIM2_CH3 PWM。

最终PA2会成为PWM输出，USART2发送功能不能正常使用。当前程序只使用USART2接收，因此暂时没有影响到`MOTOR_START`接收。

#### USART1地址1重复风险

开膛板在同一个USART1上同时使用：

- Emm地址1。
- X地址1。

如果实机两台驱动器确实共用同一组PA9/PA10并且都配置为地址1，可能出现同时响应、回包冲突或错误执行，需要结合真实接线和驱动器地址配置确认。

## 8. 出料模块

源代码入口：[`原机代码/5_出料/APP/main.c`](原机代码/5_出料/APP/main.c)

### 8.1 实现功能

1. 初始化USART1和USART2。
2. 初始化压力传感器和ADC1。
3. 等待3秒。
4. 循环读取PB0的ADC原始值。
5. 将ADC值换算为0～3.3 V电压。
6. 当前`PRESSURE_TRIGGER_ENABLED=1`：Flag4高电平发送一次`MOTOR_RUN\r\n`持续运行，Flag4低电平且没有压力事件时发送`MOTOR_STOP\r\n`立即停止。
7. 压力初始化、采样和触发代码当前参与控制。
8. 压力达到或高于0.035 V并持续20×100 ms，会在Flag4低电平时发送一次`MOTOR_START\r\n`执行有限位置运动。
9. 压力降到低于0.035 V后重新允许下一次压力事件；有限位置动作完成后自然停止。

出料板负责全部Flag4与压力决策；开膛板只把三种文本命令转换成Emm#1连续运行、有限位置运动或立即停止。

### 8.2 实际使用的传感器和通信对象

- 模拟压力传感器：1个，实际使用AO输出。
- PA6上位机允许输入：1路。
- USART2跨板通信：1路，向开膛板发送启动/停止文本。

当前没有实际控制本板上的电机。

### 8.3 实际使用的外设和引脚

| 外设/功能 | 引脚 | 用途 |
|---|---|---|
| ADC1_IN8 | PB0 | 读取压力传感器AO电压 |
| GPIO输入 | PB1 | 压力模块DO，已初始化但未读取 |
| GPIO输入 | PA6 | Flag4持续电平输入，高电平请求连续运行 |
| USART2_TX | PA2 | 发送`MOTOR_RUN`/`MOTOR_START`/`MOTOR_STOP` |
| SysTick | 内核外设 | 100 ms循环片段延时 |

USART1 PA9/PA10虽然初始化，但当前主程序没有使用。

### 8.4 压力阈值

触发阈值为：

```text
0.035 V
```

换算成12位ADC值约为：

```text
0.035 / 3.3 × 4095 ≈ 43
```

当前调用`PressureSensor_ReadRawAverage(1)`，实际上只读取一个样本，没有进行均值滤波。

### 8.5 运行风险

- 35 mV阈值非常接近零电压，容易受接地偏移和噪声影响。
- 没有迟滞区间。
- 没有要求连续多次低于阈值。
- 传感器断线或模拟输出被拉低时，可能被判断为有效压力。
- PB1数字比较输出没有参与判定。

## 11. 主要软件问题总结

1. 红外工程调用的回零参数函数存在20字节数据写入16字节数组的问题，会造成栈越界。
2. 开膛板的PA6同时被定义为DC2方向输出和上位机控制输入。
3. 开膛板的PA2同时被定义为USART2_TX和TIM2_CH3 PWM。
4. 开膛板USART1上的Emm#1与X#1存在地址重复风险。
5. 进料、去鳞和开膛现已补充PA6低电平立即停止流程；系统仍没有独立硬件急停回路。
6. 各电机命令普遍没有等待或校验驱动器执行结果。
7. 没有急停输入、看门狗和统一故障停机机制。
8. 出料压力判定只使用一次ADC采样，阈值很低且没有迟滞和去抖。
9. 红外工程中的VL53L0X距离跟随代码当前没有接入主循环。
10. 五套工程目标器件是STM32F103C8，但项目使用`startup_stm32f10x_hd.s`高密度启动文件，建议换成与实际器件密度匹配的启动文件并重新验证中断向量。
