# 3 个霍尔 + 2 个测距 + 双 F407 + 电脑上位机接线说明

## 1. 系统连接关系

```text
霍尔1 ─┐
霍尔2 ─┤
霍尔3 ─┤
测距1 ─┤→ 采集端 F407 → 接收端 F407 → USB 转串口 → 电脑上位机
测距2 ─┘
```

所有直接连接的模块必须共地。

## 2. 三个霍尔传感器连接采集端 F407

| 传感器 | 传感器信号端 | 采集端 F407 引脚 | 定时器功能 |
| --- | --- | --- | --- |
| 霍尔 1 | OUT/SIGNAL | PA0 | TIM2_CH1 |
| 霍尔 2 | OUT/SIGNAL | PA3 | TIM2_CH4 |
| 霍尔 3 | OUT/SIGNAL | PA2 | TIM2_CH3 |
| 三个霍尔 | GND | F407 GND | 共地 |
| 三个霍尔 | VCC | 3.3 V 或模块规定电压 | 供电 |

### 霍尔传感器电平注意事项

- F407 GPIO 逻辑电平是 3.3 V，霍尔输出进入 PA0、PA2、PA3 时不得超过芯片允许电压。
- 如果霍尔模块由 5 V 供电，必须确认其 OUT 是开漏输出或确认输出电压兼容 3.3 V。
- 开漏输出需要上拉到 **3.3 V**，推荐使用 4.7 kΩ～10 kΩ 上拉电阻。
- 不确定模块输出类型时，不要直接把 5 V 推挽输出接到 F407。
- 当前程序检测下降沿，三个通道均配置为 TIM2 输入捕获。

## 3. 两个 VL6180X 测距模块连接采集端 F407

两个 VL6180X 使用不同的 I2C 外设，因此可以都保持默认地址 `0x29`，不需要修改地址。

### 测距模块 1：I2C1

| VL6180X 模块 1 | 采集端 F407 | 说明 |
| --- | --- | --- |
| VIN/VCC | 3.3 V，或按模块说明供电 | 电源 |
| GND | GND | 共地 |
| SCL | PB6 | I2C1_SCL |
| SDA | PB7 | I2C1_SDA |
| XSHUT/SHDN | PC2 | 低电平关断，模块上拉后启动 |
| GPIO1/INT | 不接 | 当前程序未使用 |

### 测距模块 2：I2C2

| VL6180X 模块 2 | 采集端 F407 | 说明 |
| --- | --- | --- |
| VIN/VCC | 3.3 V，或按模块说明供电 | 电源 |
| GND | GND | 共地 |
| SCL | PB10 | I2C2_SCL（拔掉P2跳线帽） |
| SDA | PB11 | I2C2_SDA（拔掉P2跳线帽） |
| XSHUT/SHDN | PC3 | 低电平关断，模块上拉后启动 |
| GPIO1/INT | 不接 | 当前程序未使用 |

### I2C 注意事项

- SDA 和 SCL 必须上拉到 3.3 V。
- 很多 VL6180X 成品模块已经带上拉电阻，接线前应检查模块原理图。
- 如果模块没有上拉，每组 I2C 的 SDA、SCL 分别使用约 4.7 kΩ 电阻上拉到 3.3 V。
- PB10 是 SCL，PB11 是 SDA，不要接反。
- 使用PB10/PB11前应拔掉探索者板P2上的USART3功能跳线帽。
- 测距模块1的XSHUT/SHDN接PC2，测距模块2的XSHUT/SHDN接PC3。
- PC2/PC3配置为开漏输出；模块必须自带上拉，若没有，应按模块电平要求外接约10 kΩ上拉电阻。

## 4. 采集端 F407 连接接收端 F407

当前采集程序通过 USART1、115200-8-N-1 发送 16 字节传感器数据帧。

### 仅单向发送传感器数据

| 采集端 F407 | 接收端 F407 | 说明 |
| --- | --- | --- |
| PA9 / USART1_TX | PA10 / USART1_RX | 数据发送 |
| GND | GND | 必须共地 |

### 如果以后需要双向通信

再增加下面一根线：

| 采集端 F407 | 接收端 F407 | 说明 |
| --- | --- | --- |
| PA10 / USART1_RX | PA9 / USART1_TX | 命令返回通道 |

串口连接必须 TX 接 RX，不能 TX 接 TX。两个 F407 均为 3.3 V TTL 电平，可以直接连接。

## 5. 接收端 F407 连接电脑上位机

推荐使用支持 3.3 V 电平的 USB 转 TTL 串口模块，例如 CH340、CP2102 或 FT232 模块。

为了避免与接收端 F407 的 USART1 冲突，建议接收端使用另一个串口连接电脑，例如 USART2：

| 接收端 F407 | USB 转 TTL 模块 | 说明 |
| --- | --- | --- |
| PA2 / USART2_TX | RXD | F407 向电脑发送数据 |
| PA3 / USART2_RX | TXD | 电脑向 F407 发送命令，可选 |
| GND | GND | 必须共地 |
| 不连接或按供电方案连接 | VCC/3V3/5V | 不要重复给开发板供电 |

USB 转 TTL 模块再通过 USB 接电脑。

注意：这里的 PA2、PA3 位于**接收端 F407**。采集端 F407 的 PA2、PA3 已用于霍尔传感器，两块 MCU 上相同名称的引脚互不冲突。

### 串口分配建议

| 通信链路 | 接收端 F407 串口 | 引脚 | 建议参数 |
| --- | --- | --- | --- |
| 采集端 F407 → 接收端 F407 | USART1 | PA10 接收，PA9 可选发送 | 115200-8-N-1 |
| 接收端 F407 ↔ 电脑 | USART2 | PA2 发送，PA3 接收 | 115200-8-N-1 |

如果接收端开发板自带 ST-LINK 虚拟串口，应根据开发板原理图使用虚拟串口已经连接的 USART 引脚，此时可能不需要外接 USB 转 TTL 模块。

## 6. 完整接线汇总

### 采集端 F407

| 采集端引脚 | 连接对象 |
| --- | --- |
| PA0 | 霍尔 1 OUT |
| PA3 | 霍尔 2 OUT |
| PA2 | 霍尔 3 OUT |
| PB6 | VL6180X-1 SCL |
| PB7 | VL6180X-1 SDA |
| PC2 | VL6180X-1 XSHUT/SHDN（开漏控制） |
| PB10 | VL6180X-2 SCL（I2C2） |
| PB11 | VL6180X-2 SDA（I2C2） |
| PC3 | VL6180X-2 XSHUT/SHDN（开漏控制） |
| PA9 | 接收端 F407 PA10 |
| GND | 所有传感器 GND、接收端 F407 GND |

### 接收端 F407

| 接收端引脚 | 连接对象 |
| --- | --- |
| PA10 / USART1_RX | 采集端 F407 PA9 / USART1_TX |
| PA9 / USART1_TX | 采集端 F407 PA10，可选 |
| PA2 / USART2_TX | USB 转 TTL RXD |
| PA3 / USART2_RX | USB 转 TTL TXD，可选 |
| GND | 采集端 F407 GND、USB 转 TTL GND |

## 7. 上电前检查

1. 检查所有 GND 是否连接；
2. 检查 F407 输入引脚是否可能承受 5 V；
3. 检查两个 I2C 的 SDA、SCL 是否接反；
4. 检查 I2C 是否具有 3.3 V 上拉电阻；
5. 检查串口是否为 TX 接 RX；
6. 检查 USB 转 TTL 是否设置为 3.3 V 逻辑电平；
7. 避免 USB、ST-LINK 和外部电源同时从多个位置向开发板 5 V/3.3 V 电源轨供电。
