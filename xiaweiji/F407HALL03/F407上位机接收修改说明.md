# F407 上位机接收“3 个霍尔 + 2 个测距”数据修改说明

## 1. 修改目标

传感器端 F407 现在每 50 ms 通过 USART1 发送一帧数据，内容包括：

- 3 路霍尔角速度；
- 2 路 VL6180X 距离；
- 2 路测距传感器状态；
- 1 字节 XOR 校验。

原来的 14 字节帧已经扩展为 **16 字节帧**。接收端 F407 必须同步修改帧长度和字段位置。

## 2. 两块 F407 的串口接线

传感器端当前使用 USART1：

- PA9：USART1_TX；
- PA10：USART1_RX；
- 波特率：115200；
- 数据格式：8 位数据位、无校验、1 位停止位，即 115200-8-N-1；
- 电平：3.3 V TTL。

只进行单向上传时，推荐接线如下：

| 传感器端 F407 | 接收端 F407 |
| --- | --- |
| PA9 / USART1_TX | 接收串口 RX，例如 PA10 / USART1_RX |
| GND | GND |

如果还需要接收端向传感器端发送命令，再增加反向连接：

| 传感器端 F407 | 接收端 F407 |
| --- | --- |
| PA10 / USART1_RX | 发送串口 TX，例如 PA9 / USART1_TX |

注意：TX 必须接对方 RX，两块板必须共地，不要直接连接 RS-232 电平。

## 3. 16 字节数据帧定义

完整帧格式如下：

| 字节索引 | 内容 | 说明 |
| ---: | --- | --- |
| 0 | `0xAA` | 帧头 1 |
| 1 | `0x55` | 帧头 2 |
| 2 | `0x03` | 模块 ID |
| 3 | `0x0B` | 数据区长度，11 字节 |
| 4 | `omega1_L` | 霍尔 1 角速度低字节 |
| 5 | `omega1_H` | 霍尔 1 角速度高字节 |
| 6 | `omega2_L` | 霍尔 2 角速度低字节 |
| 7 | `omega2_H` | 霍尔 2 角速度高字节 |
| 8 | `omega3_L` | 霍尔 3 角速度低字节 |
| 9 | `omega3_H` | 霍尔 3 角速度高字节 |
| 10 | `distance1_L` | 测距 1 低字节 |
| 11 | `distance1_H` | 测距 1 高字节 |
| 12 | `distance2_L` | 测距 2 低字节 |
| 13 | `distance2_H` | 测距 2 高字节 |
| 14 | `range_status` | 两个测距传感器的状态 |
| 15 | `xor` | 从索引 2 到索引 14 的 XOR |

所有 16 位数据均采用**小端序**：低字节在前，高字节在后。

角速度单位为 `mrad/s`。例如接收到 `6283`，实际角速度约为 `6.283 rad/s`。

距离单位为 `mm`。VL6180X 原始测量范围为 8 位，但协议保留两个字节。

`range_status` 的含义：

- bit3~bit0：测距传感器 1 状态；
- bit7~bit4：测距传感器 2 状态；
- 状态值为 0 表示正常，非 0 表示 VL6180X 报告了测距错误状态。

## 4. 接收端数据结构

在接收端工程中新建 `sensor_rx.h`，或把下面定义放进现有协议头文件：

```c
#ifndef SENSOR_RX_H
#define SENSOR_RX_H

#include "main.h"

#define SENSOR_FRAME_SIZE       16U
#define SENSOR_HEADER_1         0xAAU
#define SENSOR_HEADER_2         0x55U
#define SENSOR_MODULE_ID        0x03U
#define SENSOR_PAYLOAD_SIZE     0x0BU

typedef struct
{
    uint16_t omega_mrad[3];
    uint16_t distance_mm[2];
    uint8_t range_status_1;
    uint8_t range_status_2;
    uint32_t valid_frame_count;
    uint32_t checksum_error_count;
    uint32_t format_error_count;
} SensorRxData;

extern volatile SensorRxData g_sensor_rx_data;

void SensorRx_Init(UART_HandleTypeDef *uart);

#endif
```

## 5. 推荐接收代码：单字节中断 + 帧头状态机

下面的实现不要求每次中断刚好收到完整的 16 字节，并能在丢字节后重新寻找帧头，适合当前每 50 ms 一帧的数据速率。

新建 `sensor_rx.c`：

```c
#include "sensor_rx.h"

volatile SensorRxData g_sensor_rx_data;

static UART_HandleTypeDef *s_uart = NULL;
static uint8_t s_rx_byte;
static uint8_t s_frame[SENSOR_FRAME_SIZE];
static uint8_t s_index = 0U;

static uint16_t ReadU16Le(const uint8_t *data)
{
    return (uint16_t)data[0] | ((uint16_t)data[1] << 8U);
}

static uint8_t CalculateXor(const uint8_t *frame)
{
    uint8_t value = 0U;

    /* XOR 范围为 module_id 到 range_status，即索引 2~14。 */
    for (uint8_t i = 2U; i < (SENSOR_FRAME_SIZE - 1U); i++)
    {
        value ^= frame[i];
    }

    return value;
}

static void ParseFrame(const uint8_t *frame)
{
    if ((frame[0] != SENSOR_HEADER_1) ||
        (frame[1] != SENSOR_HEADER_2) ||
        (frame[2] != SENSOR_MODULE_ID) ||
        (frame[3] != SENSOR_PAYLOAD_SIZE))
    {
        g_sensor_rx_data.format_error_count++;
        return;
    }

    if (CalculateXor(frame) != frame[15])
    {
        g_sensor_rx_data.checksum_error_count++;
        return;
    }

    g_sensor_rx_data.omega_mrad[0] = ReadU16Le(&frame[4]);
    g_sensor_rx_data.omega_mrad[1] = ReadU16Le(&frame[6]);
    g_sensor_rx_data.omega_mrad[2] = ReadU16Le(&frame[8]);
    g_sensor_rx_data.distance_mm[0] = ReadU16Le(&frame[10]);
    g_sensor_rx_data.distance_mm[1] = ReadU16Le(&frame[12]);
    g_sensor_rx_data.range_status_1 = frame[14] & 0x0FU;
    g_sensor_rx_data.range_status_2 = (frame[14] >> 4U) & 0x0FU;
    g_sensor_rx_data.valid_frame_count++;
}

static void ProcessByte(uint8_t byte)
{
    if (s_index == 0U)
    {
        if (byte == SENSOR_HEADER_1)
        {
            s_frame[0] = byte;
            s_index = 1U;
        }
        return;
    }

    if (s_index == 1U)
    {
        if (byte == SENSOR_HEADER_2)
        {
            s_frame[1] = byte;
            s_index = 2U;
        }
        else if (byte == SENSOR_HEADER_1)
        {
            /* 连续收到 0xAA 时保留后一个字节作为新帧头。 */
            s_frame[0] = byte;
        }
        else
        {
            s_index = 0U;
        }
        return;
    }

    s_frame[s_index++] = byte;

    if (s_index >= SENSOR_FRAME_SIZE)
    {
        ParseFrame(s_frame);
        s_index = 0U;
    }
}

void SensorRx_Init(UART_HandleTypeDef *uart)
{
    s_uart = uart;
    s_index = 0U;
    g_sensor_rx_data.valid_frame_count = 0U;
    g_sensor_rx_data.checksum_error_count = 0U;
    g_sensor_rx_data.format_error_count = 0U;

    if (s_uart != NULL)
    {
        (void)HAL_UART_Receive_IT(s_uart, &s_rx_byte, 1U);
    }
}

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if ((s_uart != NULL) && (huart->Instance == s_uart->Instance))
    {
        ProcessByte(s_rx_byte);
        (void)HAL_UART_Receive_IT(s_uart, &s_rx_byte, 1U);
    }
}

void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart)
{
    if ((s_uart != NULL) && (huart->Instance == s_uart->Instance))
    {
        s_index = 0U;
        (void)HAL_UART_Receive_IT(s_uart, &s_rx_byte, 1U);
    }
}
```

如果接收端工程已经实现了 `HAL_UART_RxCpltCallback()` 或 `HAL_UART_ErrorCallback()`，不要再定义第二个同名函数，应把上面的处理分支合并进已有回调。

## 6. 接收端 main.c 修改方法

在 `main.c` 的用户包含区加入：

```c
#include "sensor_rx.h"
```

在串口初始化完成后启动接收：

```c
MX_USART1_UART_Init();
SensorRx_Init(&huart1);
```

主循环中可以这样读取数据：

```c
uint16_t hall_1 = g_sensor_rx_data.omega_mrad[0];
uint16_t hall_2 = g_sensor_rx_data.omega_mrad[1];
uint16_t hall_3 = g_sensor_rx_data.omega_mrad[2];

uint16_t distance_1 = g_sensor_rx_data.distance_mm[0];
uint16_t distance_2 = g_sensor_rx_data.distance_mm[1];

uint8_t distance_1_ok = (g_sensor_rx_data.range_status_1 == 0U);
uint8_t distance_2_ok = (g_sensor_rx_data.range_status_2 == 0U);
```

中断会随时更新这些变量。若主循环需要保证五个测量值一定来自同一帧，可以短暂关闭中断，把 `g_sensor_rx_data` 中的测量字段复制到局部变量后再恢复中断。

## 7. CubeMX 配置要求

接收端 USART 必须配置为：

1. Asynchronous 模式；
2. 波特率 115200；
3. Word Length 8 Bits；
4. Parity None；
5. Stop Bits 1；
6. 接收模式必须启用；
7. NVIC 中启用对应 USART global interrupt。

如果使用 USART1，确认中断文件中包含：

```c
void USART1_IRQHandler(void)
{
    HAL_UART_IRQHandler(&huart1);
}
```

还需要把 `sensor_rx.c` 加入接收端工程的编译源文件列表。

## 8. 示例帧

假设：

- 霍尔 1 = 1000 mrad/s；
- 霍尔 2 = 2000 mrad/s；
- 霍尔 3 = 3000 mrad/s；
- 距离 1 = 100 mm；
- 距离 2 = 200 mm；
- 两个测距状态均正常。

发送的 16 字节为：

```text
AA 55 03 0B E8 03 D0 07 B8 0B 64 00 C8 00 00 2B
```

其中最后的 `0x2B` 是索引 2~14 所有字节异或后的结果。

## 9. 调试检查顺序

1. 不连接串口前，确认两块板没有明显电源或地线问题；
2. 确认传感器端 TX 接接收端 RX，并且共地；
3. 确认两端都是 115200-8-N-1；
4. 观察 `valid_frame_count` 是否持续增加；
5. 如果 `checksum_error_count` 增加，检查波特率、地线、线长和数据丢失；
6. 如果一直收不到数据，检查 USART 中断是否启用以及 IRQHandler 是否调用 HAL；
7. 如果能收到但数值不正确，重点检查是否仍按旧的 14 字节格式解析，以及是否按小端序合并数据。

## 10. 与旧协议的区别

| 项目 | 旧版本 | 当前版本 |
| --- | ---: | ---: |
| 霍尔数量 | 2 | 3 |
| 测距数量 | 2 | 2 |
| 总帧长度 | 14 字节 | 16 字节 |
| 数据长度字段 | `0x09` | `0x0B` |
| 第三个霍尔字段 | 无 | 索引 8~9 |
| 距离 1 字段 | 索引 8~9 | 索引 10~11 |
| 距离 2 字段 | 索引 10~11 | 索引 12~13 |
| 测距状态 | 索引 12 | 索引 14 |
| XOR | 索引 13 | 索引 15 |
